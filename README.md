# JavaScript Learning Journey

Welcome to my JavaScript learning repository! This project documents my 16-day journey mastering JavaScript, from the fundamentals of syntax to advanced concepts like Event Handling and Object manipulation.

## 📂 Project Structure

The repository is organized by days, each focusing on specific topics:

- **Day 1 - 7**: **Fundamentals & Control Flow**
  - Variable declarations (`var`, `let`, `const`)
  - Control flow (`if`, `switch`, loops)
  - Functions and basic logic
  
- **Day 8 - 12**: **Data Structures & Objects**
  - **Arrays**: Comprehensive coverage of methods like `map`, `filter`, `reduce`, `splice`, etc. (Day 8)
  - **Objects**: Creation, property manipulation (Day 12)
  
- **Day 13 - 16**: **Advanced Concepts & DOM**
  - **Events**: Event bubbling, capturing, and delegation (Day 16)
  - DOM manipulation and interactive examples

## 🚀 How to Run

### JavaScript Files (.js)
To run any of the standalone JavaScript files, ensure you have [Node.js](https://nodejs.org/) installed, then run:

```bash
node Day1/Variable_Declarations.js
```

(Replace the path with the file you want to execute)

### HTML Files (.html)
For files involving the DOM or events (e.g., in Day 16), simply open the `.html` file in your preferred web browser.
